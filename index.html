The product

Everything a short link needs, nothing it doesn't.

Hoplink is for product, marketing and growth teams at software companies who want links they can create from code, measure honestly, and wire into their own tools.

Branded short links

Generated or custom slugs, tags, expiry dates and a fallback URL for links that have ended. Archive or delete when you're done.

Click analytics

Clicks and unique visitors by day or by hour, top referrers and countries. Visitors are counted with a one-way hash: no IP addresses stored.

Signed webhooks

Created, updated, deleted and clicked events, signed with HMAC-SHA256 and retried three times, so your systems hear about every link.

Dashboard

Create and search links, read stats with charts, download QR codes, and manage webhook endpoints, without writing code.

Node.js SDK

@hoplink/node: a typed client with automatic retries, pagination helpers and webhook signature checks built in.

Command line

hoplink shorten, list and stats from any terminal or CI job, with your API key in the environment.

For developers

An API you can read in an afternoon.

Bearer API keys, JSON everywhere, one error shape, cursor pagination and a published OpenAPI contract.

import { Hoplink } from "@hoplink/node";

const hoplink = new Hoplink(process.env.HOPLINK_API_KEY);

const link = await hoplink.links.create({
  url: "https://acme.com/launch",
  tags: ["launch"],
});
const stats = await hoplink.links.stats(link.id, { period: "24h" });
console.log(link.short_url, stats.total_clicks);

FAQ

Questions people ask first

What is Hoplink?

A short link platform for developers and the teams around them: you create short links from an API, dashboard, Node.js SDK or CLI, see who clicks them, and receive signed webhooks for every event.

Do you store visitors' IP addresses?

No. Unique visitors are counted with a one-way hash of the IP address and browser; neither is stored. Referrer hosts and country codes are kept for reports.

What happens when a link expires or is archived?

It answers 410 Gone, or redirects to its fallback URL if you set one, so a finished campaign never leaves people at a dead end.

How do I know a webhook really came from Hoplink?

Every delivery carries a Hoplink-Signature header: an HMAC-SHA256 of the timestamp and body with your endpoint's secret. The SDK checks it in one call.

Is there a rate limit?

100 requests a minute per API key, with the remaining count on every response. A bulk request of up to 100 links counts as one.
